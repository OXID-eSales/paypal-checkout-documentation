PayPal Checkout V. 2.6.0
========================

Release date: 28-07-2025

New or Changed Features
-----------------------

* We have changed the navigation: Configure PayPal Checkout on the module’s :guilabel:`Settings` tab (see :ref:`configuration:Configuring PayPal Checkout`).
* Customize the layout, color, shape, and label of the PayPal Checkout buttons.

  For more information, see :ref:`configuration:Configuring PayPal Checkout Buttons`.

* The payment methods provided by :productname:`PayPal Checkout` are marked with the prefix `PayPal` upon new installation (see :ref:`oxdajr07`).

  This gives you a better overview when configuring your payment methods.

  For more information, see :ref:`configuration:Testing PayPal Checkout`, :ref:`Step 4 <adjust-prefix>`.

* Allow PayPal to process your support requests faster. By default, the transmission of your OXID eShop version number and the PayPal Checkout module version is enabled for orders.

  For more information, see :ref:`configuration:Disabling Transmitting Data to PayPal`.

* Customers can save payment information (credit card and PayPal) for later reuse during checkout and manage this payment information in their account.

  For more information, see :ref:`configuration:Using PayPal Vaulting`.


Installation
------------

To use :productname:`PayPal Checkout` V. 2.6.0, install it in your :productname:`OXID eShop` 6.3.x to 6.5.x.

For more information, see :ref:`installation:Installation`.

Update
------

To use the features and fixes of :productname:`PayPal Checkout` V. 2.6.0 in an existing installation, perform an update.

For more information, see :ref:`installation:Installing a minor update`.
